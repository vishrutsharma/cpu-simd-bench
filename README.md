# CPU SIMD Benchmark

A C++ project for learning **SIMD (Single Instruction, Multiple Data)** and understanding how CPU vectorization can improve the performance of arithmetic operations.

The project compares traditional **scalar operations** with manually implemented **AVX2 operations** using CPU SIMD intrinsics.

## Current Focus

* Scalar vs SIMD execution
* AVX2 vector operations
* CPU arithmetic performance
* Benchmarking and measuring execution time
* Understanding compiler optimizations

## Tech Stack

* C++20
* CMake
* Ninja
* AVX2
* Intel SIMD intrinsics

## Goal

The goal of this project is to explore low-level CPU performance and understand how SIMD allows a processor to operate on multiple data elements with a single instruction.

🚧 **Work in progress** — more SIMD experiments and optimizations will be added.
